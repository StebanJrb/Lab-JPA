# 🧩 JPA Laboratory

## 📘 Project Description
This project is a **Java Persistence API (JPA) laboratory**, designed to demonstrate the fundamentals of **object-relational mapping (ORM)** and database management in Java applications.  
It serves as a practical exercise for understanding how entities, relationships, and persistence contexts work within JPA.

The lab includes examples of entity creation, relationship mapping (One-to-One, One-to-Many, Many-to-Many), and CRUD operations using **JPA and Hibernate**.

---

## 🎯 Learning Objectives
- Understand the core concepts of **JPA and ORM**.  
- Define and map **entities and relationships** between database tables.  
- Perform basic **CRUD operations** using the **EntityManager API**.  
- Learn about **transactions, persistence contexts**, and **JPQL** queries.  
- Explore integration of **JPA with relational databases** like MySQL or PostgreSQL.

---

## ⚙️ Technologies Used
- **Java 17+**  
- **JPA / Hibernate**  
- **Maven**  
- **MySQL / PostgreSQL** (configurable)  
- **Persistence.xml configuration**
